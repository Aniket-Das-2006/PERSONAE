│   INTRODUCTION                                                             │
│                                                                            │
│   PERSONAE is an immersive conversational archive hosting 208 reconstructed │
│   minds from the documented historical record. This interface does not     │
│   resurrect; it establishes a reading room to consult, cross-examine, and   │
│   reason alongside history's greatest thinkers.                            │
│                                                                            │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   KEY CAPABILITIES                                                         │
│                                                                            │
│   • Provenance First  - Every statement is annotated span-by-span,         │
│                         separating document record from inference.         │
│   • Council Mode      - Query three minds simultaneously and observe       │
│                         where their perspectives align or diverge.         │
│   • Constellation     - Dynamic visual temperament mapping putting all     │
│                         208 minds within a shared universe.                │
│   • Codex Registry    - Searchable directory of credentials, signatures    │
│                         and profiles of active thinkers.                   │
│   • Reconstructive    - Custom assembly editor to build minds with unique  │
│                         reasoning paths and decision constraints.          │
│   • Debates           - Direct intellectual match-ups resolving timeless    │
│                         historical and philosophical conflicts.            │
│                                                                            │

│       $ bun install                                                        │
